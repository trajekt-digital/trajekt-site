What Trajekt automates for you

Every step of the feed lifecycle, handled automatically on your schedule.

🔌

Data extraction

Pulls your complete product catalogue from Shopify, WooCommerce, Magento, or BigCommerce via API. Every variant, metafield, collection, and image. Daily or twice-daily.

🔨

Rules transformation

Applies your configured rules on every run: title restructuring, category mapping, custom label assignment, field concatenation, HTML stripping, product filtering.

✨

AI enrichment (optional)

Claude-powered description rewriting, attribute extraction, and channel-specific copy generation. Results cached — only changed products consume credits on subsequent runs.

✅

Pre-submission validation

Checks required fields, price format, URL accessibility, EAN-13 checksum validity, and HTML in text fields — before your feed reaches any platform.

📤

Multi-format output

Generates the correct file format per channel: XML for Google, JSONL for ChatGPT, CSV for Meta/TikTok/Awin/Pinterest, and more — from the same source data run.

🔔

Error notifications

Alerts when feed runs fail so you can investigate before the issue affects your live campaigns. Email notifications for run failures and validation error spikes.

Frequently asked questions

Automated product feed management means your product data is pulled from your store, transformed and optimised, formatted for each channel, and delivered on a schedule — all without manual intervention. You configure the rules and schedule once; the automation handles every subsequent update. Price changes, new products, stock updates, and discontinued items all flow through to your advertising channels automatically.
The time saving depends on how many channels you manage. For merchants managing 3-5 channels manually (daily CSV exports, reformatting, uploading), automated feed management typically saves 5-15 hours per week. For agencies managing feeds for multiple clients, the saving is proportionally larger. Beyond time, automation also eliminates the human error risk in manual processes — incorrect prices, wrong stock statuses, missed updates.
Everything in the feed lifecycle: data extraction from your store (daily or twice-daily), field transformation (renaming, combining, splitting fields), value optimisation (title restructuring, description cleaning), validation (checking for required fields, price format, URL accessibility), format conversion (XML for Google, CSV for Meta/TikTok/Awin, JSONL for ChatGPT), and delivery (scheduled fetch URLs or SFTP push).
Feed automation with twice-daily refresh handles most pricing scenarios. For merchants with very frequent price changes (repricing software that updates prices multiple times daily), the 12-hour window between refreshes is the main lag point. Google supports Content API for near-real-time feed updates, but this requires API integration. For most UK merchants, twice-daily automated refreshes are sufficient.

A single feed run pulls your latest Shopify or WooCommerce data and outputs Google Shopping XML, ChatGPT JSONL, Meta CSV, TikTok CSV, Awin CSV, and any other configured channel formats — all in the same automated run.
Trajekt sends an error notification if a feed run fails (store API connection issue, generation error, delivery failure). The previous successful feed remains live on all platforms until the next successful run. You can trigger a manual re-run once you've resolved the underlying issue.

Manual overrides in the rules engine are applied automatically on every feed run, so they're persistent without being actually manual.
