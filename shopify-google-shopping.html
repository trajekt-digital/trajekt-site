How to connect Shopify to Google Shopping with Trajekt

Five steps from zero to a live, optimised Google Shopping feed pulling from your Shopify store.

1

Create your Shopify API credentials

In Shopify admin: Settings → Apps and sales channels → Develop apps → Create an app. Name it “Trajekt Feed”. Under API credentials, configure Admin API access scopes: read_products, read_inventory, read_content. Install the app and copy the Admin API access token — shown once only.

2

Connect your store in Trajekt

In Trajekt: Add Store → Shopify. Enter your myshopify.com store URL and paste your Admin API access token. Trajekt fetches your first full catalogue sync — including all variants, metafields, collections, and images — within 2–15 minutes depending on catalogue size.

3

Set up your Google Shopping feed rules

In Trajekt’s rules engine, create rules to optimise your feed: prepend the Shopify vendor field (brand) to titles, append colour and size variant attributes, map your Shopify product type to google_product_category, and set custom labels based on price or collection membership. Rules run automatically on every feed refresh.

4

Copy your Trajekt feed URL

Trajekt generates a stable, authenticated feed URL for your Google Shopping output. This URL always returns your latest feed data. Copy it from your Trajekt dashboard — you’ll paste it into Google Merchant Center in the next step.

5

Configure scheduled fetch in Merchant Center

In Google Merchant Center Next: Products → Data sources → Add data source → Scheduled fetch. Paste your Trajekt feed URL. Set fetch frequency to Daily or Twice Daily. Merchant Center will automatically pull your updated Shopify data on schedule — no manual uploads ever needed.
