WooCommerce Product Feed — what Trajekt does for you

🔌

REST API connection

Trajekt connects via WooCommerce REST API using Consumer Key and Secret. No plugin installation required — just enable REST API in WooCommerce settings.

🎨

Variable products

WooCommerce variable products (with size and colour variations) are correctly mapped — each variation becomes a separate feed row with shared item_group_id.

📦

Custom attributes

WooCommerce custom product attributes are pulled and available in Trajekt's rules engine — map brand, material, EAN/GTIN, and any other custom field to feed attributes.

📂

Category mapping

WooCommerce product categories map to google_product_category and product_type in your feeds. Trajekt can map your WooCommerce taxonomy to Google's taxonomy automatically.

💰

Sale price handling

WooCommerce sale prices and scheduled sale dates are pulled correctly. Trajekt outputs sale_price and sale_price_effective_date for platforms that support strikethrough pricing.

🔄

Scheduled refresh

Trajekt syncs with your WooCommerce store on your chosen schedule and regenerates all feeds automatically. New products, price changes, and stock updates are captured.

WooCommerce Product Feed — frequently asked questions

Trajekt connects via the WooCommerce REST API using a Consumer Key and Consumer Secret. Generate these in WooCommerce > Settings > Advanced > REST API. Grant Read permissions and paste the credentials into Trajekt. No plugin installation required.
Trajekt pulls: product names, descriptions, short descriptions, regular prices, sale prices, product types, categories, tags, images, SKUs, GTINs/barcodes (from custom attributes), stock status, dimensions, and all custom product attributes.
WooCommerce variable products with multiple variations are correctly handled. Each variation (size, colour combination) becomes a separate row in your feed, with its own price, SKU, and inventory status. All variations share the same item_group_id for grouping in Google Shopping and Meta catalogues.
Yes. Trajekt pulls all WooCommerce product attributes including custom ones. This is how you map brand, GTIN/EAN, material, and other product data that lives in custom attribute fields. These fields are available in Trajekt's rules engine for mapping to feed attributes.
GTINs are typically stored as a custom product attribute (e.g. EAN or GTIN) or in a plugin field like the WooCommerce Product GTIN field. Trajekt can pull GTINs from any custom attribute field — you simply tell Trajekt which attribute name contains your barcode data.
Trajekt connects to individual WooCommerce REST API endpoints. For WordPress multisite installations, each site has its own REST API and you can connect multiple sites as separate stores in Trajekt.
Trajekt works with standard WooCommerce REST API output. Any plugin that adds data to the WooCommerce product object via the API (such as GTIN plugins, custom fields, or product add-ons) will be accessible to Trajekt via the API response.
Trajekt checks stock_status from WooCommerce and maps it to the availability field — in_stock for in-stock products, out_of_stock for out-of-stock products. You can configure Trajekt to exclude out-of-stock products from your feeds entirely or include them with the correct availability value.
Yes. Trajekt fetches WooCommerce products in paginated batches via the REST API and supports catalogues of any size. Plan limits apply (50 products free, 2,000-100,000 on paid plans) but there are no technical limits from the WooCommerce API side.
Trajekt works with standard product types. Subscription and booking products can be included in your feeds, but you may want to use Trajekt's filter rules to exclude products that aren't suitable for Shopping channels (e.g. subscription-only items).
Trajekt pulls the featured image as the primary image_link and all gallery images as additional images. Up to 4 additional images are included in feeds that support them (Google Shopping, Meta, ChatGPT).

Common WooCommerce feed problems — and how Trajekt fixes them

Price mismatches — Sale prices changing in WooCommerce but not reflected in your feed until the next crawl. Trajekt’s daily refresh (or twice-daily on Growth+) keeps prices current. A manual re-run can be triggered any time before a sale launches.
Missing GTINs — WooCommerce doesn’t have a native barcode field in all versions. Trajekt maps your custom barcode/EAN attribute directly to the gtin feed field via a rule. Branded products get their GTINs; own-brand products get identifier_exists: no.
Thumbnail images — Some WooCommerce configurations export thumbnail image URLs rather than full-size images. Trajekt maps to the full-size image URL via the API, ensuring images meet Google’s 800×800px recommended minimum.
Unoptimised titles — Default WooCommerce product names are written for on-site browsing, not Shopping search matching. Trajekt rules restructure titles to the Shopping-optimal format (Brand + Product + Attributes) without changing anything in your WooCommerce store.
No custom labels — WooCommerce has no native custom label concept for Shopping. Trajekt sets custom_label_0–4 automatically via rules — by price range, category, stock level, or any field in your WooCommerce data.
