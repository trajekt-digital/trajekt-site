Connect PrestaShop to Google Shopping in 5 steps

1

Generate PrestaShop API credentials

In PrestaShop Admin: Advanced Parameters → Webservice → Add New Key. Set Permissions to GET access for: products, combinations, product_features, product_feature_values, images. Copy the generated API key. You'll also need your PrestaShop store URL.

2

Connect your store in Trajekt

In Trajekt: Add Store → PrestaShop. Enter your store URL and API credentials. Trajekt pulls your full catalogue including all products, variants, custom attributes, and images via the PrestaShop REST API (Webservices).

3

Map custom attributes and set rules

In Trajekt’s rules engine, map your GTIN/barcode attribute to gtin, your brand to brand, and configure title rules to prepend the brand and append variant attributes. Assign custom labels by price range or category.

4

Copy your Trajekt feed URL

Trajekt generates a stable feed URL for your Google Shopping output. This URL always returns your latest product data. Copy it from your Trajekt dashboard.

5

Add as Scheduled Fetch in Merchant Center

In Google Merchant Center Next: Products → Data sources → Add data source → Scheduled fetch. Paste your Trajekt feed URL and set to daily. Your PrestaShop catalogue updates in Merchant Center automatically.

Common PrestaShop gotcha: PrestaShop's Webservice API requires enabling via Advanced Parameters → Webservice → Enable PrestaShop Webservice. This is disabled by default. If you're on a managed hosting environment, your host may need to confirm that Webservice requests are allowed through their firewall.

How PrestaShop product variants map to Google Shopping

PrestaShop product combinations (the PrestaShop equivalent of variants) become individual feed rows. Each combination has a unique id (the combination reference) and shares an item_group_id with the parent product. PrestaShop's combination attributes (colour, size, material) map directly to Google Shopping's variant attribute fields.

Feed output — variant row example
id: "prestashop_variant_67890"
item_group_id: "prestashop_parent_12345"
title: "Brand Product Name — Navy — UK 12"
color: "Navy"  size: "UK 12"
price: "49.99 GBP"  availability: "in_stock"

Frequently asked questions

Trajekt supports PrestaShop 1.7 and above, which uses the standardised Webservice REST API. PrestaShop 1.6 used an older API format and is not supported — if you're on 1.6, upgrading to a current PrestaShop version is recommended for security reasons as well as feed management.
PrestaShop product combinations (variants) become individual feed rows. Each combination gets its own id (the combination reference or ID), its specific attribute values (colour, size), and a shared item_group_id matching the parent product. This is the correct structure for Google Shopping variant grouping.
In PrestaShop Admin: Advanced Parameters → Webservice → toggle 'Enable PrestaShop Webservice' to Yes. Then create a new Webservice key with GET permissions for products, combinations, and product features. Paste the key and your store URL into Trajekt.
Yes. PrestaShop product features (the custom attribute system) are accessible via the Webservice API. Trajekt pulls feature values and maps them to feed attributes via the rules engine — useful for mapping material, brand, or barcode features to their corresponding Google Shopping fields.
PrestaShop has third-party modules for Google Shopping, but these typically have limited customisation options and don't support title optimisation rules, custom labels, or multiple channels. Trajekt via the Webservice API provides a more complete and customisable feed management solution.
PrestaShop has a native EAN13 field at the combination level (and product level). Trajekt maps this directly to the gtin field — no custom attribute rule needed. If your EAN codes are stored in a product feature instead, use a Trajekt rule to map that feature to the gtin field.
