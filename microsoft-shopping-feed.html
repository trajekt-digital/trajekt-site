Microsoft offers free organic Shopping listings in the Bing Shopping tab. A valid feed is all you need — no ad spend required.

Microsoft / Bing Shopping feed format reference

Format: XML (same structure as Google Shopping). Key fields Trajekt generates from your Shopify or WooCommerce product data.

Field Example value Notes
id shopify_12345_67890 Unique variant ID
title Barbour Beaufort Jacket Navy XL Same title as Google Shopping
description Heavyweight waxed cotton jacket. Plain text
availability in stock in stock / out of stock / preorder
price 279.00 GBP VAT-inclusive, GBP currency code
link https://example.com/products/barbour-beaufort Product URL
image_link https://cdn.example.com/barbour-beaufort.jpg HTTPS, min 220×220px
brand Barbour Brand name
gtin 5055329871234 EAN-13 barcode
condition New New / Used / Refurbished (capitalised)
