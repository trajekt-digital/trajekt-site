BigCommerce feed management: connecting to every channel from one store

How BigCommerce merchants connect to Google Shopping, ChatGPT, Meta, TikTok, and more. Why native BigCommerce channel integrations fall short and how to go further without extra apps.

By Trajekt·10 Mar 2026·March 12, 2026  ·  7 min read

BigCommerce's Channel Manager connects to Google Shopping and Meta through first-party integrations. For merchants with straightforward catalogues using those two channels, it works adequately. For anyone wanting ChatGPT Shopping, TikTok, Pinterest, Awin, or Kelkoo — or deeper optimisation on Google and Meta — a dedicated feed management approach is needed.

BigCommerce's native limitations

  • No rules engine for title optimisation or field transformation
  • No AI enrichment for descriptions
  • No custom label management
  • Limited support for BigCommerce custom fields in feed output
  • ChatGPT Shopping not supported
  • Awin, Kelkoo, Idealo, Amazon, OnBuy — none supported natively

How Trajekt connects to BigCommerce

  1. Settings > API Accounts > Create API Account in your BigCommerce admin
  2. Set permissions: Products (read-only), Inventory (read-only)
  3. Copy the Client ID, Client Secret, and Store Hash
  4. In Trajekt: Add Store > BigCommerce > enter credentials

Trajekt fetches your full catalogue immediately including variants, options, custom fields, images, and categories.

Handling BigCommerce product variants

BigCommerce's option sets create variant SKUs. A common BigCommerce-specific issue: variants can have different prices but the API's basic response returns the parent price. Trajekt uses the V3 variants endpoint to pull each variant's individual price, ensuring correct price per variant in feed output.

BigCommerce custom fields

Custom fields (GTIN, brand, material, specifications) are accessible via the V3 API and available in Trajekt's rules engine. Common mappings: Custom field 'EAN' → gtin, BigCommerce Brand field → brand, Custom field 'Material' → description enrichment.

Setting up custom labels for BigCommerce Shopping campaigns

BigCommerce doesn’t have a native concept of Google Shopping custom labels. This is where Trajekt’s rules engine closes a significant gap. Instead of manually tagging products in BigCommerce, you define rules that assign labels automatically on every feed refresh.

Common label strategies for BigCommerce merchants:

  • custom_label_0 — margin tier: IF price > 100 THEN high-margin, IF price between 50–100 THEN mid-margin, IF price < 50 THEN low-margin. Enables bidding higher on products where ROAS matters most.
  • custom_label_1 — seasonality: IF category contains “Summer” THEN ss25, IF category contains “Winter” THEN aw25. Lets you increase bids on current-season stock automatically.
  • custom_label_2 — stock level: IF inventory < 5 THEN low-stock. Reduce spend on lines about to sell out, increase on well-stocked bestsellers.

Rules run on every daily feed refresh. When BigCommerce inventory drops below your threshold, the label updates automatically — no manual intervention.

BigCommerce and ChatGPT Shopping

ChatGPT Shopping processes 50 million queries daily and UK access is expanding in 2026. BigCommerce’s native channel integrations don’t support the OpenAI JSONL format required for ChatGPT Shopping — it’s a completely different spec from Google Shopping XML.

Trajekt generates ChatGPT-compliant JSONL from your BigCommerce Catalog API connection automatically. The same store connection that powers your Google Shopping feed outputs ChatGPT JSONL with correct variant_dict handling, HTML-stripped descriptions, and SFTP push delivery — no additional configuration needed once your store is connected.

What to check before connecting BigCommerce to Trajekt

Before setting up your first feed run, check these BigCommerce settings:

  • API credentials: Generate V2/V3 API credentials in BigCommerce → Advanced Settings → API Accounts. Read-only scope is sufficient for Trajekt.
  • Brand field populated: BigCommerce has a native Brand field. Ensure it’s filled in for branded products — Trajekt maps it directly to the brand feed attribute.
  • UPC/GTIN field: BigCommerce has a native UPC field. Map this to the gtin attribute in Trajekt. For products without a UPC, set identifier_exists: no via a rule.
  • Variant images: If your BigCommerce products have variant-specific images (different colours), ensure variant images are uploaded at the variant level — Trajekt will use the variant image rather than the parent product image for each row.
