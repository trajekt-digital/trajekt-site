Connect BigCommerce to Google Shopping in 5 steps

1

Generate BigCommerce API credentials

In BigCommerce Admin: Settings → API → API Accounts → Create API Account (V2/V3). Set OAuth scopes to: Products — Read-Only. Copy the Client ID, Client Secret, and Access Token. Note your store hash from the store URL (the alphanumeric string after /stores/).

2

Connect your store in Trajekt

In Trajekt: Add Store → BigCommerce. Enter your store URL and API credentials. Trajekt pulls your full catalogue including all products, variants, custom attributes, and images via the BigCommerce Catalog API (V3).

3

Map custom attributes and set rules

In Trajekt’s rules engine, map your GTIN/barcode attribute to gtin, your brand to brand, and configure title rules to prepend the brand and append variant attributes. Assign custom labels by price range or category.

4

Copy your Trajekt feed URL

Trajekt generates a stable feed URL for your Google Shopping output. This URL always returns your latest product data. Copy it from your Trajekt dashboard.

5

Add as Scheduled Fetch in Merchant Center

In Google Merchant Center Next: Products → Data sources → Add data source → Scheduled fetch. Paste your Trajekt feed URL and set to daily. Your BigCommerce catalogue updates in Merchant Center automatically.

Common BigCommerce gotcha: BigCommerce's native Google Shopping integration (via Google Channel app) works but has limited custom field access and no title optimisation rules. Trajekt via the Catalog API accesses your full product data including all custom fields, all variant options, and the native UPC field — which the Google Channel app often misses.

How BigCommerce product variants map to Google Shopping

BigCommerce product variants (called SKUs in their API) become individual feed rows. Each variant has its own id (the variant SKU or ID), specific option values (colour, size), and a shared item_group_id matching the parent product ID. BigCommerce's Catalog API V3 provides clean variant data that maps directly to Google Shopping's variant structure.

Feed output — variant row example
id: "bigcommerce_variant_67890"
item_group_id: "bigcommerce_parent_12345"
title: "Brand Product Name — Navy — UK 12"
color: "Navy"  size: "UK 12"
price: "49.99 GBP"  availability: "in_stock"
